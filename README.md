# Логопедичні презентації-ігри

Інтерактивні презентації для автоматизації звуків. Сайт публікується з папки `public/` (Netlify).

| Адреса на сайті | Презентація | Джерела |
|---|---|---|
| `/` | Тигреня Рик і звук Р — 18 слайдів | `decks/r` |
| `/s/` | Слоненя Сава і звук С — 18 слайдів | `decks/s` |

Після першого відкриття з інтернетом сторінки працюють і без нього.

## Як зробити нову або змінити

У цьому репозиторії є скіл для Claude: `.claude/skills/logo-games`. Відкрийте репозиторій у Claude Code і напишіть,
наприклад, «зроби презентацію на звук Ш» або «які є ідеї ігор». Ідеї зберігаються в
`.claude/skills/logo-games/IDEAS.md`.

Зібрати вручну:

```
python3 .claude/skills/logo-games/scripts/build.py          # усі презентації
python3 .claude/skills/logo-games/scripts/build.py s        # одну
node .claude/skills/logo-games/scripts/check.js s --shots   # перевірка
```
